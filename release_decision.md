# Итоговое решение для владельца процесса

## Решение: **ОСТАНОВИТЬ** продолжение выпуска 1.5.0-rc1.

## Основание (обязательные критерии)
- R_RESTORE — **blocked**: нет цели восстановления, RTO/RPO не доказаны.
- R_PERFORMANCE — **not_run**: измерение не проводилось.
- Контроль целостности пакета не подтверждён (нет вычисленного хеша).
- Расхождения руководства не устранены в самом пакете.
Пороги качества не снижаются ради принятия непроверенного кандидата.

## Минимальные действия для пересмотра
| Действие | Владелец | Требуемое доказательство |
|---|---|---|
| Провести тест восстановления RTO/RPO | test_owner (student_tester) | отчёт с фактическим временем и контрольным набором |
| Провести измерение p95 и успешности | test_owner | выборка, расчёт p95 = ceil(0.95·n), доля ≥99% |
| Вычислить хеш пакета и подтвердить целостность | technical_executor (student_engineer) | вычисленный хеш |
| Обновить руководство (вложения ≤3, совет при тайм-ауте) | technical_executor | исправленный фрагмент в пакете |
| Согласовать план совместимости данных при возврате | release_owner + acceptance_owner | подписанный план |

## Условие следующего рассмотрения
Повторное рассмотрение — после закрытия всех пунктов выше с доказательствами; решение принимает release_owner при подтверждении acceptance_owner.
